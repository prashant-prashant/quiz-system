# QuizMaster - Full Stack Quiz Management System

A full-stack Quiz Management System built using Django, Django REST Framework, React, and MySQL. The platform supports separate Student and Teacher functionalities with secure authentication, quiz management, leaderboard tracking, and real-time result evaluation.

---

## Features

### Student Features
- User Registration & Login
- Attempt quizzes
- Real-time score calculation
- Leaderboard system
- Quiz history tracking

### Teacher Features
- Create and manage quizzes
- Add and delete questions
- View student performance
- Dashboard analytics
